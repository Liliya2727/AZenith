## ⚡ Обзор

**AZenith** — это универсальный системный модуль для оптимизации Android. Благодаря динамическому управлению ресурсами и специальному приложению-панели управления он помогает сочетать высокую производительность в играх с экономией заряда в повседневном использовании и стабильной работой системы.

---

## 📖 Краткое руководство

### 🤖 Оптимизация

* **Приоритет процессов:** повышает приоритет игр на переднем плане и разумно замораживает ненужные фоновые приложения, освобождая системные ресурсы.
* **Автоматические профили:** автоматически переключает профиль производительности при обнаружении игры.

### 🌐 Основные возможности

* **Пользовательские профили:** ручное переключение между режимами **Производительность**, **Сбалансированный** и **Энергосбережение**. Для ручного выбора откройте `Настройки AZenith > Отключить автоматический режим`.
* **Предзагрузка игр:** загружает игровые библиотеки сразу после запуска игры.
* **Настройка CPU Governor:** позволяет выбрать регулятор частоты CPU по умолчанию.
* **Настройка I/O Scheduler:** позволяет выбрать планировщик ввода-вывода по умолчанию.
* **Ограничение частоты CPU:** помогает снизить нагрев устройства, ограничивая частоту процессора в процентах.
* **Служба Thermalcore:** интеллектуально управляет тепловыми ограничениями, предотвращая перегрев и помогая поддерживать стабильную частоту кадров.

## 📦 Установка

Это **модуль Magisk**. Установите его с помощью предпочитаемого менеджера root-модулей.

## 👨‍💻 Для разработчиков (интеграция в прошивки)

**ROM-integrated AZenith** предназначен для разработчиков и сопровождающих прошивок, которые хотят интегрировать модуль непосредственно в портированную или пользовательскую ROM.

* **Репозиторий:** [RomIntegratedAZenith](https://github.com/Liliya2727/RomIntegratedAZenith)
